# מדליקים 🕎

אפליקציה שגורמת ליותר אנשים להדליק נרות חנוכה אמיתיים, כל ערב, עם חברים, בכיף.

- תזכורת בזמן הנכון (כולל ערבי שבת, ושקט מוחלט בשבת)
- מסך הדלקה: איזה נרות, באיזה סדר, ברכות מנוקדות עם הסבר
- ניקוד ("אור"), רצף ותגים, בלי שיפוטיות
- חנוכייה משותפת עם המשפחה והחבר'ה, והזמנות "בואו להדליק אצלי"

**היעד:** בחנויות עד 25.11.2026, לפני הנר הראשון ב-4.12.2026.
